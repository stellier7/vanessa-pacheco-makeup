# Imágenes del sitio — Vanessa Pacheco Studio

Sube tus archivos en estas carpetas. El sitio los detecta automáticamente según el nombre.

## Carpetas y archivos

| Carpeta | Archivo | Uso |
|---------|---------|-----|
| `logo/` | **`logo.png`** | Logo del estudio + favicon (ícono del navegador) |
| `portrait/` | **`portrait.jpg`** | Foto de Vanessa en la sección «La artista» |
| `gallery/` | **`01.jpg`**, **`02.jpg`**, … **`08.jpg`** | Galería de trabajos (mínimo 4, hasta 8) |

### Recomendaciones

- **Logo:** PNG con fondo transparente, mínimo 200×200 px.
- **Retrato:** JPG, orientación vertical (4:5), buena resolución.
- **Galería:** JPG o WebP, orientación vertical (3:4). Nombra en orden: `01.jpg`, `02.jpg`, etc.

## Cómo subir en GitHub

1. Abre la carpeta correspondiente en el repositorio.
2. Clic en **Add file** → **Upload files**.
3. Arrastra el archivo con el nombre exacto de la tabla.
4. Clic en **Commit changes**.
