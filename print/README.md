# Logo para impresión — Vanessa Pacheco

Archivos listos para imprimir el logo en una tarjeta NFC (formato CR80, 85.6 × 54 mm, 600 DPI).

| Archivo | Cuándo usarlo |
|---|---|
| `nfc-card-black.png` | Tarjeta negra (logo blanco) |
| `nfc-card-white.png` | Tarjeta blanca (logo negro) |
| `vanessa-pacheco-logo-transparent.png` | PNG 3000×3000 con fondo transparente, para que el taller lo coloque |
| `vanessa-pacheco-logo-black.png` | Cuadrado con fondo negro |
| `vanessa-pacheco-logo-white.png` | Cuadrado con fondo blanco |

El original del sitio está en `images/logo/IMG_0654.jpeg`.
